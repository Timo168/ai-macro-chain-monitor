# 数据中心与电力区域地图

## 入口

在“AI 产业链关键指标 → 指标看板”选择“数据中心建设”或“电力与基础设施”，默认进入同一张区域地图。建设入口先显示建设图层，电力入口先显示电价图层。页面的“指标详情”切换保留原有指标图表、公司数据、全国数据和项目登记。

- 建设地图：`?page=impact&industry=metrics&category=projects#infrastructure-map`
- 电力地图：`?page=impact&industry=metrics&category=power#infrastructure-map`
- 指标详情：在上述地址增加 `&infrastructure=metrics`，或直接使用现有指标锚点，例如 `#EIA.TX.industrial`。指标链接会自动打开详情。
- “能源与原材料 → 区域电力市场”提供地图联动入口。

## 地理与数据口径

首版地图覆盖美国州级区域，边界文件、投影及授权见 [地图来源说明](geography-sources.md)。地图由当前产业缓存和区域电力缓存生成，沿用现有后台更新，不另外维护一套手工价格。

州级电价、售电量来自现有 EIA 序列；同一图层使用同一月份和同一行业口径进行比较。项目按公告披露的州定位，项目详情保留具体地点、建设状态、容量类型和来源。区域电力市场以参考标记呈现，与州界区分。

颜色代表所选指标的数值大小。建设图层的“热度”来自已登记公开项目样本的数量或适用的已披露容量；它是样本分布，覆盖范围和单位显示在页面上。全国数据及公司整体经营指标继续放在指标详情，不按公司总部位置分摊到各州。

没有记录、该月未发布、来源未配置和获取失败分别显示。已有缓存时保留观测日期与获取状态；空缺不会被画成零值。项目容量按披露类型使用，规划容量、实际投运容量与发电容量分别保留。

## 维护

接入新州的 EIA 指标后，地图从指标定义和观测记录自动识别。新项目需填写明确的国家与州代码或州名，便于定位；无法确定地区的项目保留为未定位样本。新增区域市场需要提供明确的区域参考位置，不能把电网范围简单等同于某个州。

地图展示不改变行业引擎的评分规则。图层只帮助比较建设与用电数据的地理分布，原始图表与来源链接仍可继续核对。
