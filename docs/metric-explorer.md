# 指标看板浏览方式

“AI产业链关键指标 → 指标看板”使用一张详情图配合指标目录，避免同时展开几十张图。

1. 选择产业环节，再按公司或实体筛选，也可搜索指标名称。
2. 左侧每页展示 6 项摘要，保留最新值、单位、同比、观测日期和数据状态。
3. 点击摘要切换右侧详情图；点击“收起图表”后仍可浏览摘要。公司、指标和收起状态按产业环节保存在当前浏览器。
4. 图表下方的“如何理解与产业影响”和“来源、口径与观测版本”按需展开。图表时间范围、口径、导出、事件、固定和笔记继续可用。
5. “跨公司对比”进入现有公司对比页面。项目登记、成本对比和先进封装进度放在指标浏览器后方，初次默认收起。

手机采用两列摘要、单列详情图。每个指标继续使用原来的数据和计算口径；不把不同单位的指标合并进同一坐标轴。来源失败、缓存、未配置和缺值仍分别展示。

原有指标链接、收藏和笔记保持兼容；链接中的指标会自动选择其所属产业环节，并打开对应详情。浏览器前进、后退可切回所选指标。

## 验证

- `node --test tests/metric-explorer.test.mjs`：筛选、摘要单位、缺失与缓存、深链接、分页和单图渲染。
- `node node_modules/typescript/bin/tsc --noEmit`。
- `npm run build:pages`。
- 浏览器检查：切公司、选指标、前进后退、无结果搜索、清除筛选、跨分类链接、收起记忆、无数据指标、桌面与手机布局。
