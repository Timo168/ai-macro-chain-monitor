# AI产业链关键指标：交付与使用说明

本模块替换原“AI产业链影响”，其他宏观页面继续保留。访问网站的 `?page=impact`。当前是公开数据首版，不代表大纲中的全部数据源已接通。

## 1. 页面与功能

五个子页：产业总览、指标看板、公司对比、投资结论、数据说明。总览六张状态卡区分指标趋势和配置倾向；支持搜索、分类、图表原值/同比/环比、实际拥有的历史范围、折线/柱状、缩放条、图例开关、来源及计算明细、事实数值 CSV。月度价格可以按完整季度/年度均值汇总，台积电收入则合计；缺期不会补零或插值。

公司对比以实际财季期末归入自然季度，保留真实起止日期；Oracle、Dell、AMD、NVIDIA 与自然季度不等同。五家云厂商资本开支合计只在全部公司有值时显示，并注明不是严格同期合计。成本对比采用共同月份起点=100。

## 4. 哪些环节能够形成研究结论

为云平台、数据中心、电力设备、服务器、AI 加速器、代工、封装、存储、材料和整体产业链建立了 10 个规则目标。页面把结果分成两层：直接证据、可比历史和需求主体覆盖均通过门槛时，显示正式产业研究评分；缺少其中任一项时，若已有可追溯的广义公开指标或短历史直接证据，则显示明确标注边界的先行研究信号。正式评分和先行信号都不是个股买卖建议。

## 5. 规则与置信度

规则代码：`lib/industry/engine.mjs`，版本 `industry-1.3.0`。投入、需求、建设、盈利、成本五维分别列出正反证据；同一维度按独立证据组取代表信号，同一维度出现相反证据时可形成中性，不用隐蔽分数相抵。成本和库存周转天数方向反转；一般数量/收入以同比方向取证据，利润率比较百分点。

每个产业环节均有其必需维度，必须全部取得有效证据，并达到该环节规定的需求公司覆盖数，才会生成正式建议。演示、估计、指引、未核验第三方以及过期、无基期、获取失败的数据不参与正式建议；缓存中的真实观测只有仍在有效期内才可参与，并保留失败标识。

通过数据门槛后：投入、订单、收入、盈利中至少三类指标的同比增速连续两个报告期恶化→降低暴露；两类→谨慎观望；必需维度齐备且至少四维正面、无负面维度→积极配置；至少三维正面→分批关注；正反证据冲突→中性持有；否则谨慎观望。四舍五入噪声容差为 0.05。这里的恶化指同比增速或同比百分点变化放缓，不等于绝对收入下降。

高置信度要求必需维度全部可用、直接证据具有连续可比历史、需求主体覆盖达标且无明显反向证据；其余有效建议为中，未通过门槛为低。代理数据、固定项目样本和短历史数据不进入正式评分，只进入单列的先行信号。不是投资胜率。有效期以观测期加发布节奏判断，不以最近抓取时间刷新数据年龄。

## 5.1 量化研究与受约束推理

“投资结论”页分两层工作。第一层是 `engine.mjs` 的确定性规则和 `quant-model.mjs` 的产业证据因子模型：它先固定每个产业目标的配置倾向、研究动作、置信度、直接证据、数据缺口和失效条件。第二层是可选的推理模型：它只能解释这一批已经计算好的信号组合，不能修改整体或任一产业目标的结论等级，也不能把低置信度写成高置信度。

产业证据因子模型使用需求 32%、盈利兑现 24%、资本开支 16%、建设进度 16%、成本约束 12% 的固定权重。相同公司、相同指标族先合并再计算，避免重复指标放大单一公司的影响；具有至少 8 期历史的指标以历史中位数与 MAD 作稳健强度缩放，4—7 期只标为早期方向信号，少于 4 期不会进入连续评分。模型展示的 `-100` 至 `+100` 是产业研究信号，不是预期收益率、胜率或个股交易指令。

实际收益率、金融条件和核心 PCE 只构成最多 ±10 分的宏观风险环境调整，不能替代产业的需求、盈利或建设直接证据。初请失业金因政策与需求存在双向传导，只作背景观察。任何必需维度缺失、过期、估算或来源失败时，正式分数显示“正式评分待验证”；页面会在可用时另列先行信号、数据缺口、连续历史状态和解除正式门槛所需的证据，而不是以零或猜测数值代替。

每次研究输入会把当前网站的全部已接入数据源规范成可审计摘要：每项产业指标的最近三期观测与版本、全部宏观序列的数值和状态、14 个央行政策利率、已核验的政策决议以及项目级样本。完整历史仍保留在图表和来源记录中，而不是把不同频率的历史原始值不加处理地塞入模型。每条模型引用必须精确对应指标 ID、观测期和观测版本；未发布、获取失败、过期、估算或未核验决议都会标为 `excluded`，不能作为模型结论依据。

模型在 GitHub Actions 的独立后台步骤运行，密钥只保存在 `OPENAI_API_KEY` Secret，不进入浏览器、采集器、静态数据或 Git。输入哈希只覆盖事实、状态、规则版本、提示版本与模型配置；数据未变时直接复用上次已验证结论，不重复调用。每个新输入会保存不可变输入快照、模型状态和输出哈希，`data-cache` 保留最近 200 条研究历史。模型接口未配置、请求失败、展示上次成功缓存、输出校验拒绝四种状态会分别显示。

此层输出仅是云平台、数据中心、电力、服务器、芯片等**产业环节**的研究暴露倾向与后续验证动作。它不生成公司、股票代码、买卖、目标价、仓位、收益率或胜率。项目样本、市场参考价格和未纳入规则的指标只能作背景观察，不能替代门槛证据。要验证模型是否具有投资用途，仍需在新增的版本化价格、估值、预期修正、流动性和公司行动数据上做按当时已知信息的滚动样本外回测，并纳入交易成本、换手、回撤和风险暴露。详细的证据层、状态与使用顺序见 [research-evidence-model.md](research-evidence-model.md)。

## 6. 人工复算与验证

以 MSFT 2026-06-30 现金资本开支为例：源表百万美元 35,802 / 100 = 358.02 亿美元；同比使用相同财季的上年值，公式 `(358.02 / 上年同季资本开支 - 1) × 100`。投入为正面并不能单独给出配置结论，还需需求、盈利、成本及覆盖门槛。

`recommendation-examples.json` 保存10个目标的最新可复算输入、正反证据、缺项与维度结果。运行 `node scripts/build-industry.mjs` 可重算；修改观测值或有效期后版本与结果重新生成。`verification.json` 记录83条真实序列各3期，共249个抽查点：237点通过自动来源回读或完全相同版本的既有来源核验复算，12点来自独立保存的官方事实核验台账，再复算单位与公式。当前提交中201点回读当前官方源、36点因当前来源访问失败而复用完全相同版本的既有核验；该拆分会随上游可访问性变化。人工台账对应 LBNL、Google backlog、Eaton 和 Micron，不宣称自动读取受阻页面。Dell周转天数另回读期初/期末库存与当季收入和毛利额，独立计算财季天数。该检查不证明统计覆盖完整、投资因果或再分发许可。

## 7. 本地运行

```sh
npm ci
python -m pip install -r scripts/requirements.txt
python scripts/industry_schedule.py --force

```

## 8. 自动更新与修订

现有 GitHub Actions 和 Windows 现有计划任务均约每15分钟运行宏观调度，均已接入行业调度。行业源默认按发布节奏检查，新增或失败的官方月度来源会在短间隔内重试；既有财报解析缓存最长7天；每次调度重算有效性。调度可能延迟，不承诺精确发布时间。

MSFT/GOOG/AMZN/META 使用官方已知季度 URL 规则；TSMC 按年份读取更新页；World Bank/EIA/SIA 检查公开文件/公告。Dell、AMD、NVIDIA、HPE及TSMC先进节点占比目前财报地址清单需维护；Oracle 是明确标记的核验导入。它们还不能承诺未来所有新财报自动发现。财报发布日历接入后再改为发布后重试。

新增8项自动解析由 industry_extended.py 接入每日调度；Census/FRED施工和订单环境代理由 industry_infrastructure.py 每小时检查，EIA-861M同时保留电价与原生售电量；ERCOT 月度峰值由 industry_power_load.py 低频读取公开年度档案，线上已通过完整性校验并发布44个完整月。初次升级按 collectorVersion 强制检查一次；Google backlog、Eaton、Micron和LBNL为明确标记的官方核验导入，自动采集尚未接通，核验时间不会随网页刷新改变。

来源失败保留上次成功历史：轻量Census/FRED来源按15、30、60、120分钟退避重试，其他既有采集器按日检查；脚本级异常记入 scheduler.json。网页刷新只读取缓存。SQLite 以指标/期末/版本保存修订；建议另存规则版本与观测版本。从首次采集开始形成真实版本记录，首次导入不代表过去当时已知数据。

`data-cache` 独立分支保存事实数值、解析状态、SQLite、建议历史及量化研究的输入快照；网站最多保留最近200条建议和研究历史。完整公司报告只留在本地 raw 缓存，不推送公共数据分支。密钥仍仅用于后台，行业公开源目前不需要新增密钥。

## 9. 授权与统计限制

只提取事实数值并保留原始链接，不发布整篇公司财报。SIA/WSTS 完整历史及商业报价仍需授权确认；并不因为官网可访问就取得全面再分发许可。公司 CapEx、融资租赁、分部边界和 FCF 定义各异；本模块现金 FCF=OCF−现金购置固定资产，未扣融资租赁本金，也未统一处置资产/补贴，可能不同于公司自报非GAAP FCF。Oracle 客户预付款会影响 OCF，需查看现金流构成，不能直接等同盈利增长。

## 10. 个股功能缺项

尚未联合接入股价、估值、市场一致预期、盈利预测、资产负债与财务质量、流动性及重大事件风险，因此不生成任何个股买入/卖出建议。
