# AI产业链关键指标：交付与使用说明

本模块替换原“AI产业链影响”，其他宏观页面继续保留。访问网站的 `?page=impact`。当前是公开数据首版，不代表大纲中的全部数据源已接通。

## 1. 页面与功能

五个子页：产业总览、指标看板、公司对比、投资结论、数据说明。总览六张状态卡区分指标趋势和配置倾向；支持搜索、分类、图表原值/同比/环比、实际拥有的历史范围、折线/柱状、缩放条、图例开关、来源及计算明细、事实数值 CSV。月度价格可以按完整季度/年度均值汇总，台积电收入则合计；缺期不会补零或插值。

公司对比以实际财季期末归入自然季度，保留真实起止日期；Oracle、Dell、AMD、NVIDIA 与自然季度不等同。五家云厂商资本开支合计只在全部公司有值时显示，并注明不是严格同期合计。成本对比采用共同月份起点=100。

## 4. 哪些环节能够形成建议

为云平台、数据中心、电力设备、服务器、AI 加速器、代工、封装、存储、材料和整体产业链建立了 10 个规则目标。数据满足条件时可输出云平台及 AI 加速器的配置倾向；其余环节可能因关键证据或多公司覆盖不足显示“暂不形成建议”。具体结果随数据与有效期变化，以当前快照为准。

## 5. 规则与置信度

规则代码：`lib/industry/engine.mjs`，版本 `industry-1.0.1`。投入、需求、建设、盈利、成本五维分别列出正反证据；同一维度同时存在正负证据时为中性，不用隐蔽分数相抵。成本和库存周转天数方向反转；一般数量/收入以同比方向取证据，利润率比较百分点。

优先要求该产业所需维度齐备、可用指标覆盖至少70%、至少两家该产业公司的需求证据（上游云厂商投入不能替代下游多公司验证）。演示、估计、指引、未核验第三方以及过期/无基期数据不参与正式建议。缓存有真实观测且仍在有效期内可参与，保留失败标识。

通过数据门槛后：至少三类核心指标同比变化连续两个报告期恶化→降低暴露；两类→谨慎观望；五维齐备且四维正面、无负面维度→积极配置；至少三维正面→分批关注；正反证据冲突→中性持有；否则谨慎观望。四舍五入噪声容差为0.05。这里的恶化指同比增速/同比百分点变化放缓，不等于绝对收入下降。

高置信度要求覆盖至少95%、代理指标低于20%、五维齐备且无负面证据；其余有效建议为中，未通过门槛为低。不是投资胜率。有效期以观测期加发布节奏判断，不以最近抓取时间刷新数据年龄。

## 6. 人工复算与验证

以 MSFT 2026-06-30 现金资本开支为例：源表百万美元 35,802 / 100 = 358.02 亿美元；同比使用相同财季的上年值，公式 `(358.02 / 上年同季资本开支 - 1) × 100`。投入为正面并不能单独给出配置结论，还需需求、盈利、成本及覆盖门槛。

`recommendation-examples.json` 保存10个目标的最新可复算输入、正反证据、缺项与维度结果。运行 `node scripts/build-industry.mjs` 可重算；修改观测值或有效期后版本与结果重新生成。`verification.json` 记录83条真实序列各3期，共249个抽查点：237点通过自动来源回读或完全相同版本的既有来源核验复算，12点来自独立保存的官方事实核验台账，再复算单位与公式。当前提交中201点回读当前官方源、36点因当前来源访问失败而复用完全相同版本的既有核验；该拆分会随上游可访问性变化。人工台账对应 LBNL、Google backlog、Eaton 和 Micron，不宣称自动读取受阻页面。Dell周转天数另回读期初/期末库存与当季收入和毛利额，独立计算财季天数。该检查不证明统计覆盖完整、投资因果或再分发许可。

python tests/collector_test.py

## 7. 本地运行

需要 Node 22+、Python 3.12+：

```sh
npm ci
python -m pip install -r scripts/requirements.txt
python scripts/industry_schedule.py --force
npm run dev
```

开发接口 `/api/industry` 读取原子缓存，首次可回退真实 seed。GitHub Pages 使用 `/data/industry.json`；静态产物用 `npm run build:pages` 生成。Vinext 单独生产服务的行业接口为构建时快照，需要重新构建才能更新；持续更新的正式发布路径是现有 GitHub Pages 工作流。

## 8. 自动更新与修订

现有 GitHub Actions 每30分钟运行、Windows 现有计划任务每15分钟运行宏观调度，均已接入行业调度。行业源按每日检查，新增官方文件原始缓存24小时，既有财报解析缓存最长7天；每次调度重算有效性。调度可能延迟，不承诺精确发布时间。

MSFT/GOOG/AMZN/META 使用官方已知季度 URL 规则；TSMC 按年份读取更新页；World Bank/EIA/SIA 检查公开文件/公告。Dell、AMD、NVIDIA、HPE及TSMC先进节点占比目前财报地址清单需维护；Oracle 是明确标记的核验导入。它们还不能承诺未来所有新财报自动发现。财报发布日历接入后再改为发布后重试。

新增8项自动解析由 industry_extended.py 接入每日调度；ERCOT 月度峰值由 industry_power_load.py 低频读取公开年度档案，线上已通过完整性校验并发布44个完整月。初次升级按 collectorVersion 强制检查一次；Google backlog、Eaton、Micron和LBNL为明确标记的官方核验导入，自动采集尚未接通，核验时间不会随网页刷新改变。

来源失败保留上次成功历史，下一日重试；脚本级异常记入 scheduler.json。网页刷新只读取缓存。SQLite 以指标/期末/版本保存修订；建议另存规则版本与观测版本。从首次采集开始形成真实版本记录，首次导入不代表过去当时已知数据。

`data-cache` 独立分支保存事实数值、解析状态、SQLite 和建议历史；网站最多展示最近200条建议记录。完整公司报告只留在本地 raw 缓存，不推送公共数据分支。密钥仍仅用于后台，行业公开源目前不需要新增密钥。

## 9. 授权与统计限制

只提取事实数值并保留原始链接，不发布整篇公司财报。SIA/WSTS 完整历史及商业报价仍需授权确认；并不因为官网可访问就取得全面再分发许可。公司 CapEx、融资租赁、分部边界和 FCF 定义各异；本模块现金 FCF=OCF−现金购置固定资产，未扣融资租赁本金，也未统一处置资产/补贴，可能不同于公司自报非GAAP FCF。Oracle 客户预付款会影响 OCF，需查看现金流构成，不能直接等同盈利增长。

## 10. 个股功能缺项

尚未联合接入股价、估值、市场一致预期、盈利预测、资产负债与财务质量、流动性及重大事件风险，因此不生成任何个股买入/卖出建议。
