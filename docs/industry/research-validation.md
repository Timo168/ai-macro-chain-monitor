# 研究稳定性与结论后验证

这两项回答不同的问题：稳定性检查“稍改输入，判断是否大变”；结论后验证检查“当时保存的分数，后来对应怎样的样本表现”。稳定不等于能盈利，短期上涨也不能证明模型有效。

## 当前输入稳定性

`buildResearchRobustness(calculationInputs, {inputHash})` 接收研究包已经按截止日过滤、完整归档的计算输入。归档版本必须与当前因子引擎一致；旧版本返回 `model_version_mismatch`，不使用新规则覆盖旧结果。

每个产业目标固定检验三类情景：

1. 每个所需因子权重分别降低、提高 20%，其余权重按比例重新归一。
2. 逐个移除指标的全部历史。
3. 逐个移除主体的全部指标。

移除后保留指标定义，以缺失状态重新运行建议引擎和因子引擎。连续历史、直接证据及独立主体数量等生产门槛不变。输出重算分数、方向、研究行动、评分资格及阻断因子，同时列出输入来源、发布期、版本和历史摘要 SHA-256。

“本次检验稳定”只表示这组固定扰动没有改变评分资格或方向；它不是收益区间或置信度提升。单家公司经营样本移除唯一公司后必然不能评分，应按其覆盖范围理解。

## 保存结论之后的表现

`buildResearchValidation(ledger, tracking, {asOf, registeredAt})` 只读取已真实保存的结论台账和被冻结的期满跟踪结果，不抓行情、不重建历史结论、不训练权重。

准入要求：

- 台账来源是 `live_archive`；输入摘要、目标、记录时间、分数、正式或先行层级与跟踪记录完全一致。
- 期限为 1、3、6 个月；入场日、期满日、完成日、计算保存日均通过核验，无未来观测。
- 每个证券与基准保留可用状态及行情版本；有冻结毛收益、基准毛收益和原成本口径。
- 不把尚未期满、失败、缺行情或仅有净收益的区间变成样本。

同目标、因子版本、证据层级、期限及篮子口径，按最早记录优先保留不重叠区间；不能按分数、收益、登记前后或宏观环境分别挑选出重叠样本。不同版本、层级和篮子分别展示。跨产业、跨期限仍可能重叠，所有分组相加并不是独立样本数。

分数组固定为 ≤ −45、(−45, −15]、(−15, 15)、[15, 45)、≥ 45；成本固定为每侧 0、10、25、50 基点。每个成本场景直接从冻结毛收益计算：

`净收益 = (1 + 毛收益 / 100) × (1 − 每侧基点 / 10000)² − 1`

基准使用同口径成本。不能再扣一次已保存的净收益。回撤只展示原冻结成本下的结果，不凭期末毛收益制造新每日路径。负分依然观察做多样本篮子，不通过收益取反伪造做空。

宏观环境使用信号当时归档的 `macroScore`：≥ 3 为顺风、≤ −3 为逆风，其余混合，缺失为未知。不得用今天的环境给旧信号贴标签。

## 登记与滚动对照

第一次上线保存本版本的不可变 `registeredAt`。登记前的记录归为探索；之后真实记录的信号归为前瞻。没有登记时间时全部为探索，不能自动伪称样本外。

每个已期满样本还记录它在产生时可获得的训练样本：同目标、版本、层级、期限和篮子，已到期且已经保存，完成时间早于当前信号。日期精度的保存时间按北京时间日末处理，不能用于当天更早的信号。只有同分数组至少 5 个先前样本时，才展示过去平均超额收益供滚动比较；不做参数搜索。

每组 20 个样本仅作为描述性展示门槛，不代表统计显著或策略验证。不计算胜率、Sharpe 或盈利承诺。目前真实留存时间较短，尚未期满的区间应明确显示等待，不用后来修订数据补造过去表现。

## 验证

- `tests/research-robustness.test.mjs`：重算一致性、±20% 真正归一、逐指标/主体移除、连续历史门槛、旧版本拒绝及输入不可变。
- `tests/research-validation.test.mjs`：台账精确匹配、未来/缺失/失败排除、按毛收益重算成本、跨分数组去重叠、版本/层级分离、登记前后、训练可知时点、固定分数组及不虚构做空。

测试内使用合成记录，绝不写入公开数据、采集缓存或模拟跟踪台账。
