# 个人观察与研究工作台使用说明

本次把“找数据、看变化、记录判断、回头复盘”连成一条使用流程。以下功能使用网站已有的公开数据和确定性计算；**外部推理模型继续搁置**，不会因为使用这些功能而启动模型或调用收费推理 API。

入口：[在线观察台](https://timo168.github.io/ai-macro-chain-monitor/)。侧栏新增“我的工作台”和“观察笔记”；原有图表与投资结论页继续保留。

## 1. 我的工作台：把常看指标放在一起

进入侧栏“我的工作台”，可以看到默认六张卡：初请失业金、核心 PCE 同比、十年期名义国债收益率、布伦特原油、微软资本开支和谷歌云业务收入。

- 点击“添加指标”，按中文、公司英文名或代码查找，再点“固定”。图表、公司估值详情和全站搜索结果旁也有固定入口。
- 每张卡下方的“上移 / 下移”改变排列顺序，手机上可以直接点，键盘也能操作。
- 卡片右上角的 × 取消固定。即使全部移除，也会保持空工作台，不会擅自恢复默认六张。
- 卡片保留最新有效值、单位、观测期、检查时间、来源状态和小趋势。点击“查看图表”进入完整面板；“来源”打开原始材料。
- 某份数据暂未加载时，保留原位置和收藏，不将缺值填为零，也不自动删除卡片。

同名商品的月均价和日频期货参考分别列出；名义与实际收益率、同比与环比也分别列出。收藏前先看口径，避免把它们当成同一个指标。

## 2. 全站搜索：直接找到目标面板

点击顶部“搜索指标、公司、央行”，或按 `Ctrl K`（Mac 可用 `Command K`）。例如输入“黄金”“Microsoft”“DGS10”“日本”，可以检索当前已加载的宏观、商品、产业、公司估值和央行目录。

结果显示数值、单位、观测期和状态；点击后跳转到对应页面、选择相应口径并展开目标面板。搜索框为空时，另提供“结论变化”“效果检验”“结论稳健性”“公司估值”的快捷入口。按 `Esc` 关闭搜索。

如果某个数据域仍在加载，界面会说明目录尚未完整。没有搜索到结果不等于该公司或指标没有数据；可以等加载完成后再查。

## 3. 总览变化：对照上次确认看过的版本

总览中的“这次打开，哪些值得看”跨模块汇总四类变化：新增观测、修订与补齐、获取失败、来源恢复。

第一次打开时先建立基线，**不会把网站已有的整段历史说成刚发布的新数据**。之后比较的是“上次确认已看”的版本和当前版本，刷新页面不会自动抹掉待看的变化。查看完毕后，点击“标记当前变化已看”，才会更新比较基线。

“核对跨模块更新”重新读取网站后台保存的数据。只有检查时间变了、数值和状态没变，不会制造一条更新。某个模块暂时读取失败，也不会被误判为数据消失；稍后首次成功读取的新模块先建立自己的基线。

下方“当前需要核对的来源”持续显示来源问题。点击“已看”只是确认阅读，不会清除实际的获取失败或发布延迟。

## 4. 阅读与筛选恢复：下次接着看

网站会在当前浏览器保存常用阅读设置，包括主要页面、研究子页、观察期限、公司选择、产业筛选、部分图表的同比／环比及图型、矿产的勾选与比较口径，以及面板折叠状态。

从网站根地址进入时，可恢复上次页面；带有明确参数的分享或搜索链接优先，以链接指定的页面、公司和图表口径为准。研究页里换页签或公司后，会同步更新地址，刷新可继续看该位置。

公司估值中的“本机价格／市值试算”输入不长期保存，换公司会清空，避免将上一次临时假设套到另一家公司。这里保存的是阅读选择，不承诺恢复精确滚动像素或每一项临时操作。

## 5. 图表事件：对照公告前后的变化

在支持的宏观与公司图表中打开事件层，可以查看有明确来源的宏观发布、官方利率决议和公司财报公告。事件层默认关闭，按需开启，最多展示当前区间最近的 8 个标记；列表可查看来源、实际发布时间、获取状态与版本。

周频、月频图上不一定恰好有公告当天的观测点。此时标记落在事件后第一个已有观测日，列表会同时说明**真实事件日和图中定位日**。超出区间或尚未发生的事件，不会被画成已经产生的数据，也不会延长曲线。央行横向对比图沿用原有官方决议标记。

只有来源提供了发布日期才使用，不拿“采集时间”或“月度观测日期”冒充公告日。事件标记帮助观察时间上的关系，本身不证明因果。

## 6. 企业计划兑现：核对说过什么、后来做了多少

在 AI 产业链的相关视图中查看“企业计划兑现”。表格对照较早已核验计划、后续已核验修订、实际披露和相关经营背景，并提供逐项官方来源。

当前首批是 **META 的官方核验样本**：2024、2025 年完整期间可对照，2026 年仍为未完成年度，季度实际单独展示，不计算尚未完成的全年兑现情况。记录包含已核验的计划节点，不表示已经收齐每一次历史修订。其余公司已有实际数据但尚未配齐可比指引时，显示“指引待匹配”，可以继续查看已有财报。

比较要求同公司、同币种、同单位、同起止期间和同口径。例如 META 样本的口径包含固定资产购置及融资租赁本金支付，不能直接拿网站中的现金资本开支单项替代。计划必须先于实际公布；未届满、口径不同、来源缺失或估算值不会被算成正式兑现率。

支出高于指引并不等于投资回报更好，收入也只是经营背景。新财报晚于最近核验记录时，会提示指引需要再次核验。样本覆盖、官方链接与规则见[图表事件与企业计划兑现](chart-events-and-plan-delivery.md)。

## 7. 研究笔记与每周观察报告

在指标旁点“记笔记”，或进入侧栏“观察笔记”选择关联指标，写下“我的判断”“依据与待验证条件”，可选填计划复盘日。

保存时会一并保留当时的指标数值、单位、观测期、来源状态、检查时间和已有版本标识。后来编辑笔记文字，**首次保存的数据快照不变**。在笔记里打开“当时快照与当前数据”，可检查自己的判断后来是否得到支持。复盘日期在站内列表显示“待复盘”，不会自动发送系统通知或消息。

### 备份和迁移

“导出笔记备份”生成 JSON 文件。换浏览器或电脑后，在同一功能中选择“导入 JSON 备份”。同编号记录保留本机版本，不静默覆盖；导入文件最多 5 MB，笔记最多 500 条。

JSON 用来恢复可编辑笔记；Markdown、HTML 和 PDF 是阅读与汇报文件，不能替代 JSON 备份。该备份目前只含研究笔记，不包括收藏、筛选、折叠或“已看”基线。

### 导出每周报告

在“每周观察报告”中选择该周任一天，按周一至周日汇总所选周首次保存的笔记，以及网站当前保存、具有明确发布时间的披露记录。

- **Markdown**：适合继续编辑、粘贴到文档或汇报材料。
- **HTML**：保存为独立排版文件，可在浏览器打开阅读。
- **打印 / PDF**：打开打印版，在浏览器打印对话框中选择“另存为 PDF”。若新窗口被浏览器拦截，可先下载 HTML，再打开打印。

报告末尾的“当前观察快照”是**导出时的数据**，不是所选周末已知数据；披露清单也仅覆盖网站当前保存的公开记录。因此导出过去某一周的报告，不等于还原当时全部信息或完成历史回测。报告中的个人笔记会随文件一起导出，请按自己的分享范围使用。

## 保存范围与日常用法

收藏、排列、筛选、折叠、已看基线和笔记都保存在**当前设备、当前浏览器、当前网站地址**下，不自动跨设备同步，也不会上传到仓库。本地预览与线上网站是不同地址，互不共享这些设置。清除站点数据、使用无痕窗口或更换浏览器后，记录可能不可用；重要笔记请定期导出 JSON。浏览器不允许保存时，界面会说明当前会话的限制。

一个简单的使用顺序是：先在总览看新变化，再用工作台看常用指标，点进图表对照事件和公司兑现记录，最后写下判断与下次核验条件。每周导出一次观察报告，复盘时对照保存的原始快照。所有新工具都沿用数据来源状态，不会补造观测值，也不改变现有研究评分规则。
